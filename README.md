# Dust Racing 2D 🚗💨

Dust Racing 2D ek fun aur fast-paced 2D car racing game hai jisme player different tracks par race karta hai.

## 🎮 Features
- Smooth 2D racing gameplay
- Multiple tracks and environments
- Easy controls
- Lightweight game

## 🛠️ Technologies Used
- C++
- SDL Library

## 🚀 How to Run
1. Project clone karo:
   git clone https://github.com/Aman123bhai/Dustracing2d

2. Build karo using CMake
3. Run the game
